The commit adds a Phase 1.5 call inside `dream()` in openclaw.rs:

```rust
let consolidate_opts = ConsolidateOpts::from_env();

```

`MediumBackend::consolidate_resonance` defaults to returning an "off" report (no-op) for the trait. HrmStore overrides it and calls `plan_consolidation(&self, opts)`. The signature is `&self` — an immutable borrow. The implementation:

- Iterates `self.memory_cache` (read-only)
- Builds a local `Array2` matrix (local allocation, not stored)
- Does a Gram matmul and union-find (pure computation, local variables)
- Returns a `ConsolidateReport` struct

Zero state mutation, zero effect on phases, amplitudes, or any value read by consolidation metrics. The `eprintln!` log goes to stderr, which is filtered out of L5 metric parsing. No L5 metric path is touched.
