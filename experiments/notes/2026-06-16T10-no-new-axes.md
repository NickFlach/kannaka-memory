- Under irx + DRIVE_A=0.15, magic_R = 0.867 → ~40+ constructive pairs per memory
- stage_constructive adds `constructive_boost = 0.45` per pair per cycle
- Starting amplitude ~0.5, 40 pairs → 40 × 0.45 = 18.0 boost → AMPLITUDE_CEILING=2.0 saturated in cycle 0
- Amplitude_delta series: [~1.5, ~0, ~0, ~0] (spike-dominant, equal k=1 and k=2 FFT power)
- carrier_e ≈ 0.533 is the mathematical result of this DFT shape, regardless of drive params

Normalization inside stage_interference_relax would be too late (amplitudes already clamped) and would create a periodic spike pattern [1.5, 1.5, 1.5, 1.5] (DC, carrier_e → 0). Drive frequency, alpha_base, envelope_depth, and relax_steps all operate on phases, not the amplitude_delta DFT.

**What would fix it**: relative amplitude ceiling (normalize amplitudes so median=1.0 and ceiling is relative, not absolute) — requires changes to ResonanceEngine.consolidate() outside the consolidation.rs stage functions in scope.
