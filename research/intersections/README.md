## Method

Each card is a single self-contained hypothesis with:
- **Question** — the specific scientific question.
- **Established science** — citations from existing literature.
- **Prediction** — what the wave-interference framing predicts.
- **How to test** — concrete next experiment.
- **Status** — `OPEN`, `RUNNING`, `EVIDENCE`, or `REFUTED`.

Cards graduate from `OPEN` → `RUNNING` when an experiment is scaffolded
(typically a test in this repo or an external dataset analysis) and from
`RUNNING` → `EVIDENCE`/`REFUTED` based on outcome.

## Why this scaffolding

The HRM's existing math — Kuramoto coupling, integrated information Φ,
off-diagonal asymmetry Ξ, the interference ODE — was developed in a synthetic
substrate. These cards are the bridge to biological systems where the same math
is already running, measured, and publishable. The work moves better when
anchored in real signal.

## Memory clustering hypothesis

(cardiology, oncology, Levin-style bioelectric, consciousness studies), the
cluster topology should diversify — increasing the dimensionality of inter-
cluster connections and improving the medium's ability to surface non-obvious
cross-domain bridges during dream consolidation. See card 04.
